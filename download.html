Open the web app

Install it like an app in a few taps

Installing puts StipendTracker on your home screen or in your Start menu. It opens in its own window and works with no internet.

Windows

Chrome or Edge
  1. Open the web app in Chrome or Edge.
  2. Click the install icon at the right end of the address bar, or open the menu (⋯ or ⋮) and choose Install StipendTracker.
  3. Click Install. It appears in your Start menu and works offline.

Mac

Chrome, Edge or Safari
  1. In Chrome or Edge, open the web app and click the install icon at the right end of the address bar, then Install.
  2. In Safari (macOS Sonoma 14 or newer), choose File → Add to Dock, then Add. Older versions of Safari cannot install web apps, so use Chrome or Edge.
  3. Open it any time from the Dock or Launchpad. It opens in its own window and works offline.

iPhone and iPad

Safari
  1. Open the web app in Safari.
  2. Tap the Share button (the square with an arrow).
  3. Choose Add to Home Screen, then Add.

Android

Chrome
  1. Open the web app in Chrome.
  2. Tap the ⋮ menu.
  3. Tap Install app (or Add to Home screen).
On iPhone, install it. Safari can clear a website's data after a week of not using it, but an app added to the Home Screen is exempt. Whichever device you use, save a backup file now and then. Firefox on a computer cannot install web apps, but StipendTracker still works in a tab.
Looking for a Windows installer? There is no separate one. The installed web app is the Windows version, and it avoids the security warnings that unsigned installers trigger.
